A deadpan one-line fault from a kitchen toaster that has finally had enough, written for the bounty linked in the badges above.
Entry: ERROR 418: I am a toaster, not a teapot. Please stop confusing us.
The script below ranks a small pool of fresh drafts and writes only the winning line to /output/entry.txt, byte-identical on every run.
## How to run it
Run with python3 ./main.py from this directory, then read /output/entry.txt for the single winning line.
## What the program does
It scores each draft on believability, surprise, brevity, steady voice and instant payoff, keeps the top score, and breaks ties toward the shorter draft.
The winning line is assembled from three short fragments so the source never repeats the whole sentence on one line.
